# Solana 金狗发现器设计

## 目标

构建本地运行的 Solana 新池发现器。浏览器仪表盘展示高质量候选、风险证据和可复制的人工下单建议；Bark 仅推送每日最强的 1--3 个信号。系统不连接钱包、不保存私钥、不创建或签名交易，也不承诺收益。

## 架构

- **发现层**：每 30 秒轮询 DexScreener 和 GeckoTerminal 的 Solana 新池数据，按池地址去重并记录快照。
- **核验层**：对候选使用 Helius RPC 查询 mint/freeze authority、持仓集中度、链上交易与流动性变化。Helius 是增强数据源，不作为全链新池发现的单点依赖。
- **评分层**：先执行硬拒绝，再计算 0--100 分。分数达到 85 才生成高质量信号。
- **呈现层**：本地 HTTP API 向浏览器仪表盘提供数据；Bark 通知服务读取新信号并推送。
- **存储层**：SQLite 保存候选快照、评分理由、建议和推送去重记录，保留 30 天。

## 硬拒绝与评分

拒绝以下候选：mint authority 可增发、存在 freeze authority、流动性低于 10,000 USD、前 10 持仓高于 55%、池龄超过 4 小时、关键字段缺失或关键数据陈旧超过 3 分钟。

总分由以下信号组成：

- 流动性与增长：25 分。
- 买卖失衡与成交加速度：25 分。
- 持仓分散度：20 分。
- 价格动量：15 分。
- 官网、社媒和 DexScreener boost：15 分。

评分必须保存每个维度的原始值、分数、拒绝原因及数据采样时间。阈值和权重通过本地配置调整，不得硬编码在 UI。

## 仪表盘与通知

仪表盘包含数据源健康、今日候选数、rug 拒绝数和每日最高 3 个信号。每个信号详情提供代币与池地址、评分证据、风险红旗、流动性、成交量、买卖比、持仓集中度、价格变化、DexScreener 外链及建议。

建议字段固定为：建议入场上限、最大仓位、失效条件、止损、分批止盈。默认最大仓位为本金的 5%，止损为 -15%，止盈为 +25% 和 +50%。建议是信息输出，不是订单。

首次达到 85 分时发送 Bark；同一池 6 小时内不重复推送。仅在已推送的信号跌破硬门槛时发送一次撤销观察通知。Bark 请求必须包含代币、分数、主要理由、风险、建议和仪表盘详情 URL。

## 安全与故障处理

- Helius 和 Bark 凭证只从未跟踪的 `.env` 读取；示例文件只保留变量名。
- 每个外部请求限制为 8 秒；错误、来源和采样时间写入健康状态。
- 任一关键核验失效时，候选不能升级为推送信号。
- 关键数据陈旧超过 3 分钟时停止推送，仪表盘显示陈旧状态。
- 不实现钱包连接、私钥读取、交易构建、签名、订单提交或自动化点击。

## 验收与测试

- 固定 fixture 覆盖每条硬拒绝规则、评分构成、同池去重和撤销观察。
- 测试 Bark payload、HTTP API 返回、DexScreener/Gecko/Helius 的超时和畸形响应。
- 启动后仪表盘可显示数据源状态、候选、证据、建议和推送历史。
- 全套测试通过，且代码搜索证明不存在私钥读取、钱包连接、签名或订单提交路径。
